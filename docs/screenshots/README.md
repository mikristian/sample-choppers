# UI gallery capture provenance

Every linked visual in this folder is one of three explicitly labeled types:

- **MASCHINE LAB** (`maschine-lab-native-2d-redacted.png`, `maschine-lab-3d-browser.png`, `maschine-lab-3d-lx49-browser.png`): native 2D screenshot taken directly from the installed MASCHINE LAB.app on November 14, 2026 via macOS window capture with private song/waveform/session data replaced by opaque neutral blocks; 3D browser screenshots are actual November 7, 2026 Chrome captures using synthesized demo sounds, with source available in `MaschineLab3D/`. Native 2D app source is not yet a self-contained distributable public build and is not confused with the browser emulator.

1. **CHOPROOM browser screenshots** (`choproom-*.png`): actual isolated headless Chrome captures of the source-only HTML/JS interface on November 14, 2026, with no user samples, stems or audio loaded. The main workspace, slicing tools and 16-pad controls are visible. These do not prove physical hardware routing, audio export or the installed private runtime.
2. **Native sampler GUI screenshots** (`vintage-native-board-redacted.png`, `asr10-native-keyboard-ui.png`): the Vintage Sampler Lab app was captured live on Jarvis November 14, 2026 and cropped to the app window. The former screenshot intentionally replaces the private audio waveform, selected song name and pad sample names with neutral redaction blocks; never treat it as a pixel-perfect original capture. The ASR-10 image comes from a previously saved November 2026 UI screenshot in the ASR source project and has no song library exposed. Both illustrate real interface work, not verified rebuilds of these source trees.
3. **Concept artwork** (`vintage-board-design-illustration.png`): stylized 16-pad design graphic retained from the original project. It is an illustration, not a live screenshot.

The app assets use hardware-inspired names such as ASR-10 and Akai for descriptive compatibility/reference. This work is not affiliated with or endorsed by the hardware manufacturers. No actual sound files, WAV samples, stems, private music, personal desktop paths, installer or licensed third-party controller photographs are shipped.
